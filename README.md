## Overview

This repository serves as a technical portfolio and development environment for Bash scripting. It documents the transition from manual terminal operations to engineered automation solutions, specifically focusing on capabilities required for log processing, threat hunting, and infrastructure management.

The foundational curriculum driving this lab is *The Complete Bash Scripting Course* by Dave Eddy, adapted here into practical, security-focused automation projects.

## Repository Architecture

The workspace is modularized to separate technical documentation from executable code:

*   **/scripts** — Executable Bash scripts, ranging from basic administrative tools to complex text-processing utilities.
*   **/projects** — Larger, multi-script automation frameworks and practical lab exercises.
*   **/notes** — Technical documentation, command syntax references, and workflow guidelines.
*   **/assets** — Auxiliary files, sample log data, and configuration templates used for testing.

## Technical Environment

*   **Host OS:** Ubuntu Linux
*   **Shell:** Bash (Bourne Again SHell)
*   **Version Control:** Git / GitHub
*   **Primary Focus:** Systems Administration, Log Processing, Security Operations (SOC)
